### RCA: Property Name Mismatch in `runSideEffects` Call Causes Every Issue Solver Run to Fail

#### TL;DR

Every issue solver run was failing with `Solution result is empty` despite the solution being generated correctly. The bug was a Typescript property name mismatch: the caller passed `solverResult` but the function destructured `result`, so `result` was always `undefined`. The validation added to catch empty solutions was correctly firing — but on a bug that should never have reached it.

#### What Broke and Why

The stacktrace from the exception span pinpoints both sides of the mismatch exactly. The caller in `mewtwo/src/services/issue-solver/index.ts:41`:
```typescript
// mewtwo/src/services/issue-solver/index.ts — line 41
await runSideEffects({
    run,
    customer,
    solverResult,   // shorthand for { solverResult: solverResult }
    dbOnlyMode: options.dbOnlyMode,
    notificationsEnabled: options.notificationsEnabled,
});
```

The function signature in `mewtwo/src/services/issue-solver/side-effects/index.ts:31`:
```typescript
// mewtwo/src/services/issue-solver/side-effects/index.ts — line 31
export const runSideEffects = wrapTraced(async function runSideEffects({
    run,
    customer,
    result,         // expects "result", not "solverResult" — always undefined
    ...
}): Promise<void> {
    // Validate that solution result is not empty
    if (!result || result.trim().length === 0) {
        const error = new Error(
            `Solution result is empty for runId: ${runId}. Cannot mark as completed with empty solution.`,
        );
```

Typescript shorthand property syntax means `{ solverResult }` creates `{ solverResult: solverResult }`. The function destructures `result`, which has no matching key in the passed object, so it is `undefined` on every call. The empty solution validation — which was added as a guard against genuinely empty AI output — fires immediately and correctly, but on a value that was never passed in the first place.

This is confirmed by the job failure spans:
```
bullmq.job.failed.reason: "Solution result is empty for runId: eb581e69-4677-42d6-b609-fa619edcd608.
Cannot mark as completed with empty solution."
```

And the exception at `mewtwo/src/services/issue-solver/side-effects/index.ts:31`:
```
Error: Solution result is empty for runId: eb581e69-4677-42d6-b609-fa619edcd608.
Cannot mark as completed with empty solution.
    at runSideEffects (mewtwo/src/services/issue-solver/side-effects/index.ts:31)
    at solveIssue (mewtwo/src/services/issue-solver/index.ts:41)
```

#### Fix

Rename the property at the call site in `mewtwo/src/services/issue-solver/index.ts` to match what `runSideEffects` destructures:
```typescript
// mewtwo/src/services/issue-solver/index.ts — FIXED
await runSideEffects({
    run,
    customer,
    result: solverResult,   // ← explicit mapping, not shorthand
    dbOnlyMode: options.dbOnlyMode,
    notificationsEnabled: options.notificationsEnabled,
});
```
