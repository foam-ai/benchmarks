### RCA: Hardcoded `'mewtwo'` default repo name in `issue-solver.ts` caused `git clone --bare` 404 for non-existent `foam-ai/mewtwo`

#### TL;DR

`mewtwo/src/routers/issue-solver.ts:84` contained a hardcoded fallback `const repoName = body.repoName || 'mewtwo'` that created `IssueSolverRunDocument` records with `metadata.repoName = 'mewtwo'` whenever the API caller omitted the repo name. The `foam-ai/mewtwo` GitHub repository no longer exists — it was absorbed into `foam-ai/all-the-things`. When the eval service loaded these run documents and the issue solver agent invoked `executeCommands`, it read `ctx.repoName = 'mewtwo'` and called `GitWorktreeService.createWorktree('foam-ai', 'mewtwo', ...)`, which attempted `git clone --bare github.com/foam-ai/mewtwo.git` and received a 404.

#### What Broke and Why

`issue-solver.ts:83-84` defaulted new run documents to the old repository name:

```typescript
// TODO(pcga11): Use customer ID and service ID to find repo
const repoName = body.repoName || 'mewtwo';  // 'foam-ai/mewtwo' no longer exists
```

The eval service loads historical `IssueSolverRunDocument` records created with this default. When the issue solver agent calls `executeCommands`, the tool reads `ctx.repoOwner` and `ctx.repoName` from the run's ToolContext (populated from `run.metadata`). With `repoName = 'mewtwo'`, `GitWorktreeService.createWorktree()` calls `ensureRepository()`, which finds no local bare repo and attempts a fresh clone:

```
Repository not found locally or invalid, cloning {
  repoOwner: 'foam-ai',
  repoName: 'mewtwo',
  targetPath: '/tmp/tv-base-repos/foam-ai/mewtwo'
}
→ git clone --bare "https://x-access-token:...@github.com/foam-ai/mewtwo.git" "/tmp/tv-base-repos/foam-ai/mewtwo"
→ remote: Repository not found.
```

Logs confirm the same pattern repeated across multiple concurrent eval traces (03e1c582, e81c096e, 67bbb8ee, 0408a62524) on 2026-01-22 19:22–19:44 UTC. Clones of `foam-ai/all-the-things` and `foam-ai/mono` in the same runs succeed, confirming the GitHub App token is valid and the failure is specific to the non-existent `foam-ai/mewtwo` repo.

#### Fix

One-line change in `mewtwo/src/routers/issue-solver.ts:84`:

```diff
- const repoName = body.repoName || 'mewtwo';
+ const repoName = body.repoName || 'all-the-things';
```
